# Killed ideas

The graveyard of ideas `/gauntlet` (or you) killed. **Killed ideas stay killed** unless their
revival trigger fires. This file stops the same idea coming back in four months, which makes it
the most reusable asset the skill produces.

## Update protocol

1. Add a row only on your confirmation, at verdict time.
2. Never delete a row. A revived idea gets a dated note and goes back through the gates.
3. Every row names the gate that killed it and a **revival trigger** — an external change
   (law, price, an incumbent dying) that would flip the verdict. Copy that trigger into
   `watchlist.md`.
